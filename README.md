# PullDown QR

ウェブページ上のリンクに **マウスカーソルを重ねるだけ** で、そのリンク先URLの
QRコードを **即座に表示** する Chrome 拡張機能（Manifest V3）。

クリックも右クリックもツールバー操作も不要。PCで見ているリンクを、スマホで
サッと開きたい——そんなときに画面からそのまま読み取れます。**QRの生成はすべて
端末内で完結**し、URLが外部に送信されることは一切ありません。

- 現在のバージョン: **1.7.0**
- 対応: Chrome / Edge など Chromium 系（Manifest V3）。Windows・macOS 両対応
- ライセンス: Apache-2.0

## 特長

- **ホバーで即時表示** — リンクに乗せた瞬間にQRがポップアップ（遅延は調整可、0で完全即時）
- **クリックで画像コピー** — QRを左クリックでPNG画像をクリップボードへ（「✓ QR画像をコピーしました」）。右クリックの「画像をコピー」「名前を付けて画像を保存」やドラッグでの持ち出しも可
- **クリックでリンクコピー** — QR下のURLを左クリックでリンク文字列をコピー（「✓ リンクをコピーしました」）。ドラッグで部分選択も可
- **完全ローカル処理** — QRは端末内で生成。ネットワーク権限なし・外部送信なし・トラッキングなし
- **不要な場所では出さない** — 既定で**外部リンクのみ**を対象にし、今いるサイト内のリンク（GitHubのコミット、SNS、管理画面などのアプリ内リンク）や、検索タブ・ページャ・ナビゲーションを自動で抑制。サイト単位の除外も可能
- **細かく調整可能** — サイズ / 誤り訂正レベル / 表示位置 / 色 / 表示遅延 / URL併記
- **ショートカット** — `Alt+Shift+Q`（Macは `Option+Shift+Q`）でオン/オフ
- **誤表示防止モード** — 「Option（⌥）/ Alt を押している間だけ表示」に切替可能。**リンクに合わせたままキーを押すと表示**、離すと非表示
- **現在ページのQRをワンクリック** — ツールバーアイコンを押すと、ポップアップに今開いているページのQRを表示（クリックで画像/リンクをコピー）
- **Windows / macOS 両対応** — 表記とショートカットを実環境に合わせて自動表示（Macは ⌥）

## インストール（開発者モードで読み込み）

ストア未公開のため、開発者モードで読み込みます。

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオン
3. **パッケージ化されていない拡張機能を読み込む** をクリック
4. このフォルダ（`manifest.json` がある階層）を選択

ツールバーにアイコンが追加されたら、任意のページでリンクにホバーしてください。

> **更新を反映するとき（重要）**: コードを変えたら `chrome://extensions` で該当拡張を
> **再読み込み** し、**さらに開いているページを再読み込み（⌘R / F5）** してください。
> Chromeは拡張をリロードしても、すでに開いているタブの中では古いコンテンツスクリプトが
> 動き続けるため、ページを更新しないと新しい挙動（同一サイト抑制など）が反映されません。

## 使い方

### 基本

- 任意のリンクにカーソルを重ねる → QRが表示される
- カーソルを外す / ページをスクロール / `Esc` キー / 別の場所をクリック → 消える
- ツールバーのアイコンをクリック → ポップアップ上部に **今開いているページのQR** を表示（クリックで画像/リンクをコピー）。あわせて 有効/無効・QRサイズ・Altモード・「このサイトでは無効」を切替
- ポップアップの「詳細設定…」→ 全設定＋ライブプレビュー

> **アドレスバー（URL欄）について**: 「URL欄をクリックしたら出す」はできません。
> アドレスバーはブラウザ自身のUIで、拡張機能からは検知も上描きもできないためです
> （Chromeのセキュリティ仕様）。同じ目的（今のページをQR化）は、上記の
> **ツールバーアイコン1クリック**で実現します。Chrome標準のアドレスバー右の共有/QR
> アイコンからも現在ページのQRを出せます。

### QR画像をコピー / 保存

- QRを **左クリック** → PNG画像をクリップボードへコピー（チャットや画像編集にそのまま貼り付け可）
- QRを **右クリック** → ブラウザ標準メニューの「画像をコピー」「名前を付けて画像を保存」
- QRを **ドラッグ** → 他アプリやデスクトップへ画像として持ち出し

### リンク（URL）をコピー

- QR下のURLテキストを **左クリック** → リンク文字列をクリップボードへコピー
- URLを **ドラッグ** すると従来どおり部分選択でき、その場合はコピーは発火しません

### Option（⌥）/ Alt モード（押している間だけ表示）

「誤表示を抑えたい」「必要なときだけ出したい」場合は、設定で
**「Option（⌥）/ Alt キーを押している間だけ表示」** をオンにします。

- キーを押しながらリンクにホバー → 表示
- **すでにリンクにカーソルを合わせている状態でキーを押しても表示**（ホバーし直す必要なし）
- キーを離すと非表示

> macOS では DOM 上 Option（⌥）が Alt として扱われるため、Option キーがそのまま使えます。
> 表記も自動で Mac 用（Option（⌥））を先頭に並列表示します。

### ショートカット

- `Alt+Shift+Q`（Macは `Option+Shift+Q`）で拡張全体のオン/オフ
- 割り当ては `chrome://extensions/shortcuts` から変更可能。ポップアップには **実際に割り当てられているキー** が表示されます

## 設定項目

ポップアップ（簡易）と詳細設定ページの両方から変更でき、変更は即座に全タブへ反映されます。

| 項目 | キー | 既定値 | 説明 |
|---|---|---|---|
| 有効 | `enabled` | オン | 拡張機能のマスタースイッチ |
| Option/Alt を押している間だけ表示 | `requireAlt` | オフ | 誤表示を抑えたい場合にオン（Macは Option（⌥）） |
| 表示までの遅延 | `hoverDelayMs` | 60ms | 0で完全即時。上げるとマウス移動時のチラつきを抑制 |
| QRサイズ | `qrSize` | 184px | 表示されるQRの目標サイズ |
| 誤り訂正レベル | `ecc` | M | L/M/Q/H。高いほど汚れ・歪みに強いが密になる |
| 表示位置 | `position` | リンクの下 | `link`（リンク基準）/ `cursor`（カーソル追従） |
| URLテキスト | `showUrl` | オン | QR下にURLを併記（クリックでコピー可） |
| モジュール色 / 背景色 | `darkColor` / `lightColor` | `#10151c` / `#ffffff` | QRの前景・背景色 |
| 同じサイト内リンクで非表示（外部のみ） | `skipSameSiteLinks` | オン | 今いるサイトと同じドメインへのリンク（アプリ内リンク）を抑制し、外部リンクだけに絞る |
| 同一ページ内リンクで非表示 | `skipSamePathLinks` | オン | 検索タブ・ページャ等（同一パスでパラメータ違い）を抑制 |
| ナビゲーション領域で非表示 | `skipNavLinks` | オン | `<nav>` / `role="navigation"・"tablist"・"tab"・"menu"・"menubar"` 内を抑制 |
| 除外サイト | `excludedSites` | なし | 指定ホスト（サブドメイン含む）で完全無効。ポップアップからワンタッチ追加可 |

設定は `chrome.storage.sync` に保存され、同じ Google アカウントでサインインした
Chrome 間で同期されます。

## 不要な場所での非表示（チェック機能）

「どこでもホバーでQRが出る」と、GitHubのコミットリンクやサイトのメニューなど、
QRが不要な場所でも出てしまいます。QRは「**今見ているものをスマホなど別の場所で開く**」
のが主目的なので、既定では **外部リンク優先** とし、次の4層で絞り込みます。

1. **同一サイトリンクの抑制**（`skipSameSiteLinks`, 既定オン）★今回の主役
   **今いるサイトと同じドメイン**（サブドメイン関係を含む）へのリンクを抑制します。
   例: github.com を見ているときの github.com 上のコミット/ファイル/PRリンク、
   SNSや管理画面の「アプリ内リンク」など。これらは手元のPCで見ているサイト内の移動なので、
   通常QRは不要です。同一サイトのページもQRにしたい場合はオフに。
   （`a.github.io` と `b.github.io` のような公開サフィックス配下の別サブドメインは
   別サイトとして扱い、抑制しません。）
2. **同一ページ内リンクの抑制**（`skipSamePathLinks`, 既定オン）
   現在のページと **オリジン＋パスが同じでクエリ/ハッシュだけ違う** リンクを抑制。
   Google検索のタブ（`?udm=…`）、ページャ（`?page=2`）、並べ替え・絞り込みなどが該当。
3. **ナビゲーション領域の抑制**（`skipNavLinks`, 既定オン）
   `<nav>` や `role="navigation" / tablist / tab / menu / menubar` の内側のリンクを抑制。
4. **サイト除外**（`excludedSites`）
   特定ホストで丸ごと無効化。`google.com` と書くとサブドメインも対象。
   ポップアップの「このサイトでは無効」トグルから現在のサイトをワンタッチ追加できます。

このほか、`javascript:` `about:` `blob:` `data:` などのスキーム、同一ページ内の
`#フラグメント` ジャンプ、2048文字を超える極端に長いURLは常に対象外です。

## プライバシーと権限

- **QR生成・コピー処理はすべて端末内（ローカル）で完結します。** ネットワーク通信は一切行いません。
- 解析（アナリティクス）やトラッキングは **ありません**。
- 要求する権限は最小限です。

| 権限 | 用途 |
|---|---|
| `storage` | 設定（上記の各項目）の保存・同期 |
| `clipboardWrite` | QR画像 / リンクをクリップボードへコピー |
| `content_scripts: <all_urls>` | 各ページ上でリンクの `href` を読み取り、その場でQRを描画するため（読み取った値は外部送信されません） |

ホスト権限の追加要求や、`tabs` の閲覧権限などは要求していません。
詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## 仕組み（アーキテクチャ）

| ファイル | 役割 |
|---|---|
| `src/content.js` | 全ページに注入。`<a href>` の `mouseover` を検知し、Shadow DOM のカード内にQRを表示。コピー・表示位置・抑制判定・Optionキー処理などの中核 |
| `src/qr-render.js` | QR描画の共通モジュール（`pdqrDrawQR`）。content/popup/options が共有 |
| `src/vendor/qrcode-generator.js` | QRエンコード（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator), MIT, © Kazuhiko Arase） |
| `src/defaults.js` | 既定設定・設定取得ヘルパ・プラットフォーム判定（全コンテキスト共有） |
| `src/background.js` | Service Worker。既定値の初期化、ツールバーバッジ、ショートカット処理 |
| `src/popup.html` / `popup.js` | ツールバーの簡易設定UI |
| `src/options.html` / `options.js` | 詳細設定ページ（ライブプレビュー付き） |

要点だけ:

- QRは **オフスクリーン `<canvas>` に描画 → `data:image/png` の `<img>` として表示**。
  これにより右クリックの標準メニュー（画像コピー/保存）やドラッグがそのまま使えます。
- カードは **Shadow DOM** で隔離され、ページ側のCSSの影響を受けません。
- 設定は `chrome.storage.onChanged` で監視し、開いている全タブへ即時反映します。

イベントの状態遷移・コピー実装・抑制ロジック・テスト構成などの詳細は
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) にまとめています。

## アイコンについて

ツールバーアイコン（`icons/icon16.png` ほか）は画像編集ソフトを使わず、
**スクリプトでプログラム生成** しています。生成元は
[`tools/gen-icons.mjs`](tools/gen-icons.mjs) です。

```bash
node tools/gen-icons.mjs   # icons/icon16・32・48・128.png を再生成
```

特徴とポイント:

- **外部依存ゼロ。** Node 標準モジュールだけで動作します（`node:zlib` で DEFLATE 圧縮、`node:fs` / `node:path` / `node:url` でファイル出力・パス解決）。
- **PNGエンコーダを自前実装。** PNGのシグネチャ＋ `IHDR` / `IDAT`（zlib圧縮）/ `IEND`
  チャンクを組み立て、各チャンクの **CRC32** を計算しています（8bit RGBA、フィルタなし）。
- **描画もコードで完結。** RGBAバッファに矩形を塗るだけのシンプルな描画関数で、
  QRらしいモチーフを描いています。
  - 角3か所に **ファインダパターン**（同心の四角：外枠＝青 → 中抜き＝透明 → 中心＝青）
  - 右下の空き領域に **3×3のデータ風チェッカー**
- **色は単色の青 `rgb(37, 99, 235)`、背景は透過。** ライト/ダーク両方のツールバーで視認できます。
- **サイズは比率で計算。** 余白 9%、ファインダは内側領域の 42% といった比率で、
  16 / 32 / 48 / 128px それぞれにきれいに収まるよう自動算出します。

要するに「**本物のQRの見た目（3つのファインダ＋データ）をコードで描き、
Nodeだけで有効なPNGとして書き出している**」というものです。配色やモチーフを
変えたい場合は `gen-icons.mjs` の `BLUE` や `drawIcon()` を編集して再生成してください。

## 開発とテスト

実ブラウザでの自動E2E検証を [`test/run-verify.mjs`](test/run-verify.mjs) に用意しています。
Puppeteer（Chrome for Testing）に拡張を読み込み、ローカルのテストページでホバー操作を行い、
**表示されたQRを [jsQR](https://github.com/cozmo/jsQR) でデコードしてURL一致まで** 確認します。

```bash
cd test
npm install          # 初回のみ（puppeteer, jsqr を取得）
node run-verify.mjs  # 全チェックを実行（スクリーンショットは test/artifacts/ に出力）
```

カバーしている主な項目: ホバー表示/非表示、ネスト/SVG/日本語/長すぎるURLの扱い、
クリップボードへの画像・リンクコピー（読み戻し検証）、不要な場所の抑制、除外サイト、
設定トグルの動作と保存、Option/Alt の表記とホバー中キー操作、カードのレイアウトなど。

> ブランド版 Chrome 137+ は `--load-extension` を廃止したため、自動検証には
> Puppeteer 同梱の **Chrome for Testing** を使います。手動確認は前述の
> 「開発者モードで読み込み」で行えます。

## トラブルシューティング / FAQ

- **更新したのに古い挙動のまま（同一サイトでもQRが出る等）** → 拡張のリロード後に
  **ページを再読み込み（⌘R / F5）** してください。開いていたタブには古いコンテンツ
  スクリプトが残っているためです（再読み込みで解消）。
- **設定を変えたのに反映されない** → ほとんどは即時反映されます。挙動がおかしい場合は
  `chrome://extensions` で拡張を **再読み込み** ＋ページ再読み込みを。
- **特定のサイトでQRが出ない** → そのサイトが「除外サイト」に入っていないか、
  リンクがナビゲーション領域内/同一ページ内リンクで抑制されていないか確認してください
  （ポップアップ／詳細設定で確認・解除できます）。
- **左クリックでQR画像がコピーできない** → ごく一部のサイトは
  `Permissions-Policy: clipboard-write=()` でクリップボード書き込みを禁止しています。
  その場合はトーストが「コピー不可 — 右クリックで保存」と案内するので、右クリックの
  「画像をコピー」をご利用ください。
- **ショートカットが効かない** → Chrome は競合回避のため推奨キーを自動割り当てしないことが
  あります。`chrome://extensions/shortcuts` で手動設定してください。
- **iframe 内のリンクで出ない** → パフォーマンス優先で、コンテンツスクリプトは
  最上位フレームのみ（`all_frames: false`）に注入しています。
